# CriptoSuite — Herramienta Académica de Criptografía

Aplicación web interactiva desarrollada como complemento académico para el módulo de Criptografía de la **Escuela Superior Politécnica del Litoral (ESPOL)**.

Demo en vivo: [sauls98.github.io/criptografia](https://sauls98.github.io/criptografia.github.io)

---

## Herramientas disponibles

| Módulo | Descripción |
|---|---|
| Cifrado César | Encriptación/desencriptación con shift (C ≡ P + b mod 26) |
| Cifrado Afín | Encriptación/desencriptación afín (C ≡ aP + b mod 26) |
| Euclides y MCD | Algoritmo extendido de Euclides con representación de Bézout |
| Inverso Multiplicativo Modular | Cálculo de ā⁻¹ mod m con validación de existencia |
| Teorema Chino del Residuo | Resolución de sistemas de congruencias |
| One-Time Pad | Cifrado OTP con generador de llave aleatoria |
| Criptosistema RSA | Generación de claves, encriptación y desencriptación |

Cada herramienta muestra el proceso matemático paso a paso.

---

## Uso

No requiere instalación. Abre directamente en el navegador:
O clona el repositorio y abre `criptosuite.html` localmente:

```bash
git clone https://github.com/sauls98/criptografia.github.io.git
```

---

## Descarga

Disponible en la sección **Recursos** dentro de la aplicación:

- `CriptoSuite.exe` — versión de escritorio Windows (no requiere Python)
- `criptosuite.py` — código fuente Python (requiere `sv-ttk`)
- `criptosuite.html` — esta misma página para uso local
